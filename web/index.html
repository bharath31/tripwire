the failure your linter cannot see

Your skill description is routing code.

The agent reads a skill’s name and description before deciding whether to load it. A clean file proves the syntax works. It does not prove the agent will choose the skill.

silent miss

The user asks for the right outcome.

The wording differs from your description, so the agent never loads the skill. Nothing crashes. The user gets a generic answer.

false trigger

The skill claims too much territory.

An unrelated prompt matches the description. The agent loads the wrong instructions and interferes with work it should have ignored.

from guesswork to a testable contract

Test the behavior. Commit the evidence.

  1. 01
    tripwire analyze

    Probe the skill with real prompts

    Tripwire generates core, edge, negative, and paraphrased prompts, then runs the selected agent in an isolated read-only workspace.

  2. 02
    tripwire-scenarios.yaml

    Review the expected behavior

    Each prompt carries an explicit should-activate or should-stay-quiet expectation. Edit the contract, then commit it beside the skill.

  3. 03
    tripwire test

    Block the regression in CI

    Replay the same scenario set on every skill change. Tripwire separates behavioral failures from agent timeouts and authentication errors.

a real activation signal

Tripwire watches the agent load your skill.

It does not ask an LLM whether your description “looks good.” The Claude adapter reads the structured Skill tool event from a real session and matches the skill that fired.

Gemini and Codex adapters are available as experimental checks. Their confidence level is reported instead of hidden.

first behavioral result in three commands

Test one real prompt locally.

Use your existing agent login for a one-prompt activation check. Generate the broader matrix when the basic path works.

$ npm install -g tripwire-skills
$ tripwire lint ./skills/my-skill
$ tripwire test ./skills/my-skill --prompt "your real user prompt" --expect activate

The one-prompt check does not need a Tripwire account or a separate generation key. analyze can then generate a larger positive and negative scenario matrix.

a review signal your team can enforce

Gate skill changes on every pull request.

The Action lints changed skills, replays committed activation scenarios, annotates the diff, and posts one sticky PR summary. Missing credentials skip the paid probe and leave static lint running.

  • Runs on your GitHub runner
  • Uses your model credentials
  • Distinguishes misfires from broken infrastructure
# .github/workflows/tripwire.yml
name: Tripwire
on: pull_request
jobs:
  skills:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v5
        with: { fetch-depth: 0 }
      - uses: bharath31/tripwire@v1
        with:
          probe: true
          anthropic-api-key: ${{ secrets.ANTHROPIC_API_KEY }}

The skill is personal and low-stakes.

If you are the only user, normal use will expose most activation problems. Tripwire earns its place when a silent failure reaches someone else.

production questions

What skill developers need to know.

What does Tripwire test?

Tripwire tests whether a real agent activates a specific Agent Skill for prompts that should match and stays quiet for prompts that should not. It compares structured activation signals with explicit expectations and turns those cases into regression scenarios for local and CI runs.

How is Tripwire different from a SKILL.md linter?

A linter checks file structure and authoring rules. Tripwire also runs the skill through a real agent and observes whether it activates. That behavioral check catches valid-looking descriptions that miss intended prompts or trigger for unrelated requests.

Does Tripwire upload my skill or prompts?

Tripwire does not send skill files, prompts, file paths, repository names, model output, usernames, or credentials to its servers. Probes run locally or on your GitHub runner through your configured agent provider. Anonymous behavioral telemetry can be disabled with TRIPWIRE_TELEMETRY=0.

Which agents does Tripwire support?

The Claude Code adapter is live-verified and recommended for production gates. Codex CLI and Gemini CLI adapters are available as experimental checks with their confidence level reported explicitly.

How much does Tripwire cost?

Tripwire is free, MIT-licensed open-source software. Static lint is free to run. Behavioral probes use your existing agent login or provider credentials, so any model usage is billed by your provider rather than Tripwire.
